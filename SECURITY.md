# Security

sidenote runs a local server that can put text in front of your Claude Code session, so its
security matters. The documentation's [Security](docs/index.html#security) section describes how the API is
protected.

## Reporting a vulnerability

Please report security problems privately through
[GitHub's security advisories](https://github.com/sous17/sidenote/security/advisories/new),
not in a public issue. Include what you found, how to reproduce it, and what an attacker could
do with it. You'll get a reply within a week.
